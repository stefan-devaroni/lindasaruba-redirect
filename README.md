# lindasaruba.com

Forwarding page for lindasaruba.com (no dash). Every address on that domain sends
visitors to the Linda's Dutch Pancakes online shop:
https://app.amazecommerce.com/shop/lindasaruba

To change where it goes, replace the shop address in `index.html` and `404.html`
(they are identical; `404.html` catches old links to pages that no longer exist).
